## WAX & WICK PRODUCTION SPEC

### Formula Requirements
- **Wax:** Soy-coconut blend (natural, clean burn, no paraffin)
- **Fragrance Load:** 10% (strong throw, not cloying)
- **Wick:** Dual cotton, self-trimming (no mushrooming)
- **Pour:** Hand-poured in Chicago facility
- **Cure:** 14-day minimum before ship (optimal scent development)

### Quality Standards
- [ ] **Cold Throw:** Detectable at 3 ft unlit
- [ ] **Hot Throw:** Fills 400 sq ft room within 30 min
- [ ] **Burn:** Even melt pool to edge by 2nd burn
- [ ] **Soot:** Zero visible soot on vessel/lid
- [ ] **Scent Fidelity:** Matches approved oil sample ±5%

### Testing Protocol (Pre-Launch)
1. **Oil Sample Approval** — W&W sends 3 iterations per scent → Founder approves
2. **Test Burn** — 3 full burns per vessel (waste allowed) → verify throw/burn/soot
3. **Ship Test** — Ship to 3 addresses (hot/cold/humid) → verify arrival condition
4. **Community Blind Sniff** — Discord members (no labels) → vote on descriptions
