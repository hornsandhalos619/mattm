## RISK MITIGATION

| Risk | Mitigation |
|------|------------|
| **Brand rejects** | Apply to 8+ brands; need 3-5 approvals. Have backup list (Timberland, Palladium, Oliver Peoples). |
| **Low sell-through** | Curate tightly (6-8 SKUs/brand). Bundle aggressively. Community pre-sell via Discord. |
| **Return complexity** | Collective handles returns. Clear PDP messaging: "Curated partner — returns to brand." |
| **Brand conflict** | Exclusive chapter tie-ins prevent overlap (Vans=Ch I, ASICS=Ch II, JMM=Ch III). |
| **Margin pressure** | No discounting. Bundle value-add (chapter card, sticker) not price reduction. |
